## How to use in the new SEMrush
1. Create **two Position Tracking campaigns** for capitalwealth.com: "Federal Benefits" and "Traditional Retirement." Set device = Desktop, location = **United States** (national) AND add **Utah** as a second tracked location (so we see both — recall: nationally the calculator is #11-15, in Utah it's #1).
2. Paste the bucket's keywords (flat lists handed off in chat) into each campaign.
3. Mirror the two buckets as **Keyword Manager** lists for ongoing research (run Keyword Magic / Keyword Gap vs myfedbenefitshelp.com, myfeba.org, fedlaw.com to expand the federal bucket).
4. Federal is the priority — weight tracking + content there first.
